# Hospital Emergency Operations Analytics

## Project Overview

This project analyzes hospital emergency department operations using PostgreSQL and SQL.

The analysis focuses on patient flow, waiting time, doctor workload, department performance, and emergency operations.

## Tools Used

- PostgreSQL
- pgAdmin4
- SQL
- Git & GitHub

## Database Tables

- Patients
- Doctors
- Visits

## Key Business Questions

- What is the average patient waiting time?
- Which department receives the most emergency visits?
- Which doctor handles the highest number of patients?
- What time of day has the highest patient volume?
- Which triage level has the longest waiting time?
